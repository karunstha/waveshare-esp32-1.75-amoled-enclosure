# Real print photos

Put photos of your printed enclosure in this directory. Suggested names:

- `front.jpg` — display installed, viewed straight on
- `back.jpg` — cover installed
- `inside.jpg` — component tray and clips before closing
- `usb-c.jpg` — plug fit at the bottom edge

Then replace the placeholder in the root README with the image links. Keep the
images reasonably small (about 1600 px on the longest edge) so the GitHub page
loads quickly. Avoid showing serial numbers or other details you do not want
to publish.
